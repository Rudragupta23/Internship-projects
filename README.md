## 🛠️ Project 1: TODO App

The `todo-app` is a complete full-stack web application designed to help users manage their daily workflows efficiently. 

### ✨ Features
* **Create Tasks:** Add new tasks seamlessly.
* **Read Tasks:** View a dynamic list of all pending and completed tasks.
* **Update Tasks:** Edit existing tasks or mark them as complete.
* **Delete Tasks:** Remove tasks that are no longer needed.
* **Responsive UI:** Clean and modern interface styled with Tailwind CSS.

### 💻 Tech Stack
**Frontend:**
* React.js
* Vite (Bundler)
* Tailwind CSS

**Backend:**
* Node.js
* Express.js

## ⚙️ Getting Started (Local Development)

To run the TODO app on your local machine, follow these instructions:

### Prerequisites
Make sure you have [Git](https://git-scm.com/) and [Node.js](https://nodejs.org/) installed on your computer.

### Installation & Setup

### 1. Clone the repository
git clone https://github.com/Rudragupta23/Internship-projects.git

### 2. Navigate to the project directory
cd Internship-projects/todo-app

### 3. Start the Backend Server
Open your terminal and run:
cd backend
npm install
npm start

### 4. Start the Frontend Application
Open a new, separate terminal window and run:
cd frontend
npm install
npm run dev
