# ⚙️ Getting Started

Follow these steps to run any project locally on your machine.

## Prerequisites

Make sure the following are installed:

- Git
- Node.js (v18 or later)
- npm

---

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Rudragupta23/Internship-projects.git
cd Internship-projects
```

---

## 2️⃣ Run Frontend-Only Projects

Examples:
- Movie Search
- Dictionary App
- Weather App

Navigate to the desired project folder:

```bash
cd <project-folder>
npm install
npm run dev
```

Example:

```bash
cd Movie-Search
npm install
npm run dev
```

---

## 3️⃣ Run Full-Stack Projects

Examples:
- TODO App
- Expense Tracker
- Student Management

You must start both the backend and frontend servers separately.

### Step 1: Start Backend Server

Open a terminal and run:

```bash
cd <project-folder>/server
npm install
npm run dev
```

or

```bash
cd <project-folder>/backend
npm install
npm run dev
```

---

### Step 2: Start Frontend Application

Open a new terminal window and run:

```bash
cd <project-folder>/client
npm install
npm run dev
```

or

```bash
cd <project-folder>/frontend
npm install
npm run dev
```
